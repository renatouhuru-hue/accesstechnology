# OS Accesstechnology

Aplicativo de ordens de serviço, orçamentos e recibos para TI (Accesstechnology).

## Stack
- Vite + React + TypeScript + Tailwind CSS
- Supabase (dados na nuvem)
- Vercel (deploy)

## Configuração
Copie `.env.example` para `.env.local` e preencha as variáveis do Supabase e da IA.

## Scripts
- `npm run dev` — desenvolvimento
- `npm run build` — build de produção
- `npm run lint` — checagem TypeScript
